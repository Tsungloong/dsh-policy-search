# 安装与使用

## 安装一次，在 DSH 对话中使用

安装 `dsh-policy-search-0.2.0.tgz` 到 DSH 0.2.1-rc.2 的目标 profile 并重启。使用插件页“本地安装”，或：

```sh
dsh plugin --profile web add /absolute/path/dsh-policy-search-0.2.0.tgz
```

Windows 绝对路径加引号。首次解析依赖需要联网；文件生成可离线完成。使用 DSH 已有模型、搜索和网页读取设置，插件 config 保持空对象。

## 三种用法

**检索但不生成文件**：在对话中提出地区、行业、主题和日期范围，DSH 调用检索、读取、核验工具后直接回答。

**检索并制作文件**：补充“生成 Excel 和 Word”。同一个核验结果可反复导出为不同格式，不重新搜索或调用额外模型。

**独立制作文件**：提供文字、表格和需要的格式。DSH 整理 document 内容后直接调用 policy_office，不要求搜索服务或政策任务。

结果返回文件绝对路径。默认位于宿主数据目录的 policy-search/exports 下。如需放到项目目录，让 DSH 使用已有文件工具移动；插件不绕过宿主文件操作授权。

## 常见情况

- 搜索服务未配置：在 DSH 配置，或直接给政策网址；不会自动切换为有限目录扫描。
- 网页读取失败：错误原样返回，当前会话记录失败来源；不会伪装成“没有政策”。
- PDF 链接无扩展名：使用 policy_read 的 format=pdf。扫描件需要 OCR；二进制下载使用系统网络，不内置 DNS 绕行。
- 非政府域名：可读取，发布主体另行核对，不用改白名单。
- 没有申报日期或多个批次：保留原文说明，日期为空，不把发布日期或有效期代成截止日期。
- 同名文件：选择新文件名；默认名称包含唯一 ID。
- 中文字体：PDF 内嵌字体；Word/Excel 使用 Noto Sans CJK SC，未安装时由编辑器替换。字体随包提供。
- 取消：使用 DSH 原有停止操作；已保存的原文与完整结果保留。

## 升级与历史结果

先停用/卸载同 profile 中的旧包，再安装 0.2.0。旧包的数据目录保留。若原来设置过 dataDir，沿用原值可继续按旧任务 id 导出；其余旧配置不再使用。

移除的工具是 policy_workbench 和 policy_job。policy_search 改为直接返回候选，核验结果由 policy_check 返回。新流程没有前端页面、后台任务或定时运行。
