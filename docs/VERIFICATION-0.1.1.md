## 对齐官方候选版，不绕过检查

官方发布：[DSH v0.2.1-rc.2](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-rc.2)。核对 npm 后，`next` 指向 `0.2.1-rc.2`，但 `latest` 仍是 `0.2.0-rc.2`。本次明确选择用户宿主所在的候选基线。

新旧 peer 混用时 npm 正常拒绝解析。本次从清单重建一致的锁文件并执行 `npm ci`，没有使用 `--force`、`--legacy-peer-deps` 或版本豁免。
